# 韩叙短视频口播写稿 Skill

把你想说但还没讲清楚的东西，整理成观点明确、自然可讲的完整口播稿。

适合有专业经历、个人想法或已有文章，想拍口播但写起来很散的人。你可以直接讲自己的想法，不必先写提纲、填问卷或想好商业模式。Skill会先理清这一条要讲什么，再组织论证、写完整稿，并根据你的试读反馈修改。

当前版本：**v0.1.0**。这是可安装到AI助手中的方法包，需要可用的Codex或能读取`SKILL.md`及其配套文件的助手；不附模型服务。核心写稿无需其他业务Skill、平台登录、API密钥、Python或剪辑软件，AI工具费用由你自己的账号承担。

## 安装

把下面的话复制到Codex：

```text
请用 $skill-installer 从 https://github.com/hanxu66/hanxu-video-script/tree/v0.1.0/skills/hanxu-video-script 安装韩叙短视频口播写稿Skill，技能名 hanxu-video-script。保留完整技能目录，核对入口和引用。已有同名旧版时先保留备份到技能发现目录之外，再更新；不改其他技能。告诉我实际安装位置并确认能够读取。
```

也可从[最新Release](https://github.com/hanxu66/hanxu-video-script/releases/latest)下载`hanxu-video-script-v0.1.0.zip`。Mac与Windows的目录、层级、更新及排错见[安装说明](INSTALL.md)。

## 第一次使用

```text
用 $hanxu-video-script 帮我写一条口播。
我做项目管理，想讲给刚开始独立接项目的人听。
最近遇到的事是：客户说只改一点，我没问具体是哪几处就答应了，后来发现涉及整套方案。我重新和对方确认修改范围，才继续做。
我想表达：答应之前，先把“改一点”变成双方都知道的具体事项。
请帮我理清观点和结构，给完整口播稿。只使用这些事实，缺关键材料就问我，别编结果。
```

这是虚构的使用示例，请换成自己的真实材料；不预设你有客户、收入或上述经历。你也可以给一篇自己的完整文章，或一段零散想法。[更多用法与改稿示例](USAGE.md)

## 你会拿到什么

- 本条的核心判断与简短推进思路。
- 可复制、可试读的完整口播逐字稿。
- 正文之外的可选画面建议及真实待补项。
- 按你的反馈局部修改或整合后的一个当前版本。

目标是帮助你把自己的内容讲清楚。最终还需本人试读和调整，文字检查不代表已经拍摄或验证真人听感；不承诺爆款、完播、获客或收入。

## 独立使用与隐私

用户配置从空白开始。只使用你本次提供或授权的材料，不附韩叙的客户资料、私人案例、个人声音、历史样稿、内部数据库或整套工作流。支持仅在对话使用；需要文件时保存在你自己的工作目录，和技能安装目录分开。不要将私人材料提交到本仓库或公开Issue。

它只负责口播写稿与改稿。选题可以由你自己提供，也可以来自其他工具；写稿不以安装选题、商业模式或剪辑包为条件。拍摄、剪辑、发布按你自己的后续安排处理。

## 方法、验证与维护

沿用韩叙已有的观点立意、内容结构、逐字稿和反馈学习方法，独立适配只移除私人配置与系统依赖。方法来源及适配边界见[PROVENANCE.md](PROVENANCE.md)。[发布标准](RELEASE-STANDARD.md)区分结构测试、实际行为测试和真人使用效果；实际验证范围见[VALIDATION.md](VALIDATION.md)及[GitHub Actions](https://github.com/hanxu66/hanxu-video-script/actions)。

开发者可用Python 3.9以上重建安装包，使用者写稿不需要Python：

```bash
python -m unittest discover -s tests -v
python scripts/build_release.py --output dist/hanxu-video-script-v0.1.0.zip
```
