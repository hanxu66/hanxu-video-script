# 观点立意

沿已有写稿方法，先确定这一条唯一要证明的判断。回读用户的完整原话、已选话题和可用来源，不用另找一个流行观点替换用户的意思。

1. 写出目标观众当前相信什么、通常怎样做。没有依据时作为理解假设，不能冒充调研结论。
2. 从用户的判断、真实经历或全文材料中，写出本条要成立的一句话。纠偏型要说清常见理解漏了什么原因、条件、关系或取舍；实用方法型可凭具体用法和可用结果成立，不强行制造反常结论。
3. 选一条能支持同一判断的核心证据链。展开当时在处理什么、卡在哪里、做了什么、现在有什么变化；失败、返修和局部试用同样可以成为证据，不要求成功或成交。客户自述须保留归属。用户提供的外部作者经历不能改成用户亲历。
4. 对照证据确定成立条件、不适用情况和可能反例。建议、计划、局部测试、实际执行和效果分别表述；用一次经历支持的判断不能扩成普遍保证。
5. 用日常话说清观众看完能改变哪个理解或动作。逐项对照准备讲的材料，不能支持这一判断的移出本条；不能靠增加建议数量制造收获感。

阶段结果保留五项：**观众原来的理解、用户当前判断、核心依据、成立边界、观众收获**。可以简洁呈现或保存为工作记录，不必把长表格交给用户填。

文章改编保留原核心、证据和边界，再选这条短视频的重点；长文章中并列的几个观点可以拆开，不在一次短口播里全部塞入。只有外部标题、介绍、标签时，作者的完整观点和论证未知。除非用户明确委托参考具体作品并提供可核验完整内容，否则不补造原作者想法。

用户只有题名或泛泛判断时，围绕一次具体经历追问，例如当时在做什么、哪一步卡住、怎样处理、发生了什么变化。资料已经足够就继续结构与全文；关键事实确实缺失时说清缺口，不用“还不了解你”无限访谈，也不先编一篇第一人称稿。
