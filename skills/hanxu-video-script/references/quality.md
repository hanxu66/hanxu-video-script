# 实际成稿检查

本表用于回读实际正文和来源后修正问题。勾选、字数、关键词或文件存在不能证明稿子好；没有通过的部分如实说明，不能只发自评结果。

1. **立意**：五项立意清楚；正文能复述唯一判断。认知差别或实用收获具体，有支持同一判断的核心证据及适用边界。
2. **结构**：开头与承接回答同一问题，段落连续；因果、并列、转折真实成立。案例前后扣回判断，方法有可执行起点、顺序和判断标准；没有第二个独立议题或二次升华。
3. **听觉理解**：第一句遮住标题仍明白；必要人物、主语、指代、前提齐全。把分类词和压缩结论改成可听懂的人、动作、原因和结果，不用堆语气词替代口语化。
4. **事实归属**：每个影响结论的事实能回到用户材料或本次实际核验来源。逐项核对案例句，以及为承接和解释补入的前提，不能把合理推测写成已发生事实。个人经历、客户自述、外部观点、建议和假设分开；不造对白、情绪、动机、数据、授权、完成状态或效果。
5. **参考作品**：仅标题/摘要不冒充全文；明确要求结构参考时完整拆解和映射。没有挪用作者身份、案例或特色原句，不靠同义替换或改动百分比放行。
6. **个人表达**：学的是本次用户的原话及真实反馈，未把韩叙的业务、身份、样本、固定措辞或私人配置带入。没有样稿时不伪称学会其风格。
7. **返修范围**：局部修改对照版本差异；范围外内容保持，必要扩改有具体说明。新事实与纠正已经反映到所有受影响结论。
8. **可交付性**：交出完整可复制正文，画面建议和待补项分开；需要演示才能成立的内容明确缺口。没有把文字检查说成真人试读、成片、发布或流量效果。

上游判断不清就回立意，因果跳跃回结构，听觉不自然改逐字稿，事实不足补最小证据。资料足够时检查后同轮继续，不增加形式性人工确认。
