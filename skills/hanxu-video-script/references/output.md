# 交付与保存

先交给用户能读、能试的成果。通常依次呈现：

- 一句说明本条核心判断；用很短的段落解释推进思路。用户要看完整立意或结构时展开对应阶段，不能只给概念名称。
- **完整口播逐字稿**：从第一句到最后一句，分自然段；不用大纲、半成品或内部状态表代替正文。若用户只要求局部改稿，可交替换段并明确起止边界；要求整合时给完整当前稿。
- **正文外的画面备选**：至少两种可替代材料，各自说明对应位置、显示什么、证明什么以及已有/待补。不假定素材已经取得；正文独立成立时可纯口播拍摄。
- 必要的事实缺口、授权或演示待补，以及希望用户试读后反馈的具体位置。没有实际核验的真人听感、时长与效果如实保留未知，不堆泛化免责声明。

用户已有标题且要求保留就沿用；需要另起标题时，承诺须由正文兑现。可按要求另交封面短句或发布介绍，但不自动扩为找题、设计图片、剪辑和发布。

用户不必保存文件也能使用。本地保存为可选方式：在用户工作目录分开保存来源、完整稿、修改反馈与简短续接记录，记录一个当前版本。更新技能只替换安装目录，不影响工作目录里的用户资料。不默认上传、同步、建立数据库、自动化或删除历史。
